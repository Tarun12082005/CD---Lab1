# Compiler Design Lab Experiments (Lab 1 - Lab 6)

## Overview
This repository contains the complete implementation of Compiler Design Laboratory Experiments using C++. Each experiment is organized into its own folder with source code and a dedicated README.

## Repository Structure

Lab-03-NFA-to-DFA/

Lab-05-FIRST-FOLLOW/
Lab-06-Predictive-Parsing-Table/

LAB7-15/

## Technologies Used
- C++
- GCC / G++
- VS Code
- Git
- GitHub

## Lab List
The repository includes programs for lexical analysis, regex to NFA conversion, NFA to DFA conversion, left recursion elimination, FIRST and FOLLOW computation, predictive parsing table construction, and later compiler design lab exercises.

## How to Run
1. Open the required `.cpp` file in VS Code.
2. Compile it using `g++ filename.cpp -o output`.
3. Run it with `./output`.
4. Provide input as mentioned in the respective lab README.
